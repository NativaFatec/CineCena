# Frontend CineCena

O frontend usa HTML, CSS e JavaScript puro.

## Regra de organização

- **HTML:** estrutura, seções e textos.
- **CSS:** visual e responsividade.
- **JavaScript:** comportamento e componentes reutilizáveis.
- **data.js:** dados simulados e curadoria.
- **tmdb.js:** integração com o TMDB.

Não existe mais um `app.js` responsável por montar páginas inteiras.

Para alterar uma página visualmente, comece pelo arquivo correspondente em `pages/`.
