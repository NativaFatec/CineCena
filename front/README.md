# CineCena Showcase

A static visual showcase of **CineCena**, an academic social network concept focused on Brazilian cinema and movie reviews.

This version is not functional yet. It was created to present the project idea, layout, pages, and navigation using only static files and mock data.

## About

CineCena is a movie review and social platform concept inspired by websites such as Letterboxd, with a focus on Brazilian cinema.

The platform allows users to explore movies, write reviews, rate films, interact with other users, and discover Brazilian productions through a social and academic-oriented experience.

All users, movies, reviews, comments, and other content in this repository are fictional and used only for demonstration purposes.

## Pages

The showcase includes:

- fake login page
- home page
- movie catalog
- movie details page
- user profile
- movie reviews
- review details
- search page
- rankings and featured movies

## Technologies

- HTML
- CSS
- JavaScript
- Bootstrap
- Tailwind CDN

## Important note

This is only a front-end showcase.

There is no real login, backend, database, or data persistence. The buttons and actions are only visual, created to demonstrate how the final project could look and how users could navigate through the platform.
